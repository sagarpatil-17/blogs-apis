## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Access to the configured database, if required

### Installation

```bash
git clone https://github.com/sagarpatil-17/blogs_apis.git
cd blogs_apis
npm install
```

### Environment Variables

Create a `.env` file with the variables required by your application.

Example placeholders:

```env
PORT=3000
DATABASE_URL=
JWT_SECRET=
```

### Run the API

Use the command defined in your `package.json`. For example:

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
